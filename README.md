## 🛠️ Technical Architecture & Build Quality

We built this on a **modern, event-driven architecture** that prioritizes sub-millisecond input latency. The entire training loop runs on a **continuous render pipeline** that decouples physics from the display rate, ensuring that even on midrange hardware, your inputs are captured with surgical precision.

- **Responsive Engine**: The UI adapts fluidly from a 4K desktop monitor down to a mobile portrait view. Touch input is treated as a first-class citizen with a separate calibration profile.
- **Local-First State Management**: Your data is stored locally using a lightweight embedded database, giving you **instant load times** and **full privacy**. No accounts required to start training.
- **Progressive Web App Ready**: Install it to your dock for a **native-app feel** without the bloat of a giant binary.

## 🚀 Getting Started: Your First Forging Session

1. **Initiate the Forge** – Open the application. The UI language will automatically match your browser's locale (supporting 12+ languages, including English, Spanish, Japanese, German, and more).

3. **Enter the Training Loop** – Start the standard session. The objective is simple: **strike the target when the inner ring aligns perfectly with the outer ring**. The window of success is about 100 milliseconds.
4. **Review & Adjust** – After 50 successful "bonks," the session ends. Review your analytics dashboard and tweak your session length (from 1-minute sprints to 25-minute deep-work marathons).
